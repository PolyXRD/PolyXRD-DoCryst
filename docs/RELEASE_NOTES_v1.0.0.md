# PolyXRD DoCryst v1.0.0（稳定版）

XRD 结晶度分峰定量分析工具。依据 MDI Jade 6 全谱拟合惯例：**C = A_c/(A_c + A_a) × 100%**，FWHM > 3.0° 的峰形组分判为非晶。采用面积归一化伪 Voigt 峰形（解析面积恒等，无截断误差），有界最小二乘（scipy TRF）背景 + 全峰联合拟合，支持逐峰手动添加/移动/锁定/类型覆写，σ(C) 由全峰面积协方差传播得到。

## 主要特性

- **面积归一化伪 Voigt**：pV(x) = A·[η·L(x) + (1−η)·G(x)]，组分面积 ≡ 参数 A（解析恒等，宽非晶晕无积分截断误差）
- **非晶判据**：拟合后 FWHM > 3.0°（0.5–15° 可调），逐峰手动覆写并锁定
- **背景模型**：多项式（默认，2–5 阶联合拟合）、两端点直线（Jade 惯例）、线性最小二乘、锚点、SNIP（递增窗口 Ryan 变体）、无
- **手动分峰**：画布点击添加峰、拖拽移动、表格编辑（位置/FWHM/面积/η/类型/三锁列）、逐峰固定锁、共享 η
- **诊断**：覆盖率、Rwp、R²、halo_edge 比（>3% 提示端点偏差）、FWHM 触界、阈值临界峰
- **σ(C)**：全峰面积协方差传播（含峰间相关），含背景参数
- **三语界面**：简体中文 / English / 日本語（无回退显示 ⟪key⟫ 以便发现缺译）
- **批量分析**：多文件队列，失败跳过并记录，CSV 报告（UTF-8 BOM）
- **产物**：HTML 报告（内嵌 PNG、峰表含 d 值）、CSV、PNG、工程文件 `.dcy.json`（含 30 步撤销）
