## 1. 合成数据真值恢复（tests/test_core.py）

合成谱：3 支尖峰（FWHM 0.18–0.25°，Ac=50000）+ 1 个宽包（FWHM 9°，Aa=60000），
解析真值 C = 45.455%。

| # | 场景 | 背景 | 拟合 C | 偏差 | Rwp | 判类 |
|---|---|---|---|---|---|---|
| 1 | 无噪、无基线 | none | 45.45% | +0.00 pp | 0.0000 | 3C+1A ✓ |
| 2 | 含噪 σ=12（seed 3/11/23） | none | 45.50% | +0.04 pp | 0.019 | 3C+1A ✓ |
| 3 | 含噪 σ=12 | poly o3 | 45.43% | −0.03 pp | 0.023 | 3C+1A ✓ |
| 4 | 递减指数背景 | poly o3 | 45.61% | +0.15 pp | 0.019 | 3C+1A ✓ |
| 5 | 递减指数背景 | 端点直线 | 53.44% | **+7.98 pp** | 0.101 | 3C+1A（Aa 被背景吃掉） |
| 6 | 平基线 | 端点直线 | 49.57% | **+4.11 pp** | 0.051 | 3C+1A（同上） |
| 7 | 纯非晶 | none | 0.00% | — | — | 0C+1A ✓ |
| 8 | 纯结晶 | none | 100.0% | — | — | 3C+0A，warn.no_amorphous ✓ |

结论：**背景口径正确时恢复误差 < 0.2 pp；端点直线口径存在固有正偏差**（表 5/6），
工具已内置检测（`warn.halo_edge`，非晶包端点强度比 > 3% 触发）并在方法说明中
给出处理建议（多项式背景或缩窄区间）。该偏差属 Jade 传统口径的固有属性，
横向对比保持同口径即可。

σ(C) 验证：含噪场景 σ ≈ 0.03–0.09 pp，与重复拟合的实测散布（±0.05 pp）量级一致。

## 2. 防劈裂（anti-split）

（面积 60072 vs 真值 60000，FWHM 9.00 vs 9.0）。

## 5. 已知边界（v1.0.0）

- 手动锚点背景（anchors）可通过工程存档配置，界面暂未提供锚点编辑器；
- Kα2 剥离未接入（面积比法对 Kα2 不敏感——双线面积同计入总散射）；
- 峰多（>25）时全谱拟合约 1–2 分钟/谱（含协方差与迭代补峰），批量时自动
  关闭协方差估计可提速；
- 面积比法结果为**相对结晶度**，受背景口径、判据与区间选择影响，对比实验
  必须同口径（方法说明与报告内已注明）。
